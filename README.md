# Sistema Ômega

Proposta e protótipo interativo do painel interno da Ômega (Gestão & Pessoas).

- `index.html`: apresentação da proposta (dores, o que muda, rotina com automações, módulos, etapas).
- `painel.html`: protótipo do painel com dados de exemplo. Abas acessíveis por link direto (`painel.html#jobs`, `#meetings`, `#reports`…); `?tour=1` mostra o roteiro de boas-vindas.

Nada é enviado: WhatsApp, Google Forms e IA são simulados. Alterações ficam salvas só no navegador de quem usa.
